# MiMo Language Analysis App

An app written in R to analyse language data, with a specific focus on helping clinicians to analyse child language. It could also be used as way to teach grammar / word classes. The app aims to be a more user-friendly, but less powerful alternative to the [CLAN language analysis system](https://dali.talkbank.org/clan/)

The web app (located at [https://mimolanguageanalysis.uk](https://mimolanguageanalysis.uk)) runs in web assembly so all data stays within the browser.

Before using it, please visit the documentation at [https://docs.mimolanguageanalysis.uk](https://docs.mimolanguageanalysis.uk)

If you do not wish to be dependent on the website, the app.R file may also be run in R environment (e.g. RStudio). This will act more or less like a standalone application, except that internet access will be needed to run the parsing libraries.

Please contact [Nick Riches](www.gmail.com) for feedback, or support.
